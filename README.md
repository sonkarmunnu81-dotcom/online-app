# CareerPath — Online Career Guidance Portal for Underprivileged Students

## Description
CareerPath is a responsive frontend-only educational portal built with HTML5, CSS3 and Vanilla JavaScript. It helps students explore careers, complete a basic assessment, understand education pathways, discover scholarship portals, find learning resources and access official career resources.

## Objectives
- Make career information easier to access.
- Provide a simple career assessment experience.
- Explain education and skill pathways.
- Connect students to official scholarship and government resources.
- Offer free-learning discovery and saved-item functionality.

## Features
- Responsive navigation with mobile menu
- Career search and category filtering
- 20-question assessment with score output
- Dynamic career details
- Scholarship discovery with official-source links
- Free course catalogue
- Government/career resources
- Demo registration/login using localStorage
- Saved careers and courses
- Dashboard and learning progress
- Dark mode persisted in localStorage
- English/Hindi toggle UI
- Accessible labels, focus states and responsive layouts
- Back-to-top button

## Technology Used
HTML5, CSS3, Vanilla JavaScript, localStorage.

## How to Run in VS Code
1. Open the project folder in VS Code.
2. Install/use the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Test navigation and features in the browser.

## How to Use
1. Register a demo student account.
2. Open the assessment and answer all questions.
3. View the result and dashboard.
4. Explore career cards and detailed roadmaps.
5. Save careers/courses.
6. Visit Scholarships and Resources and use official website links.
7. Try dark mode and the language toggle.

## Browser Requirements
A modern browser such as Chrome, Edge, Firefox or Safari with JavaScript enabled.

## Limitations
- Authentication is a frontend demo and is not suitable for real credentials.
- Scholarship data is intentionally general; users must verify live eligibility and deadlines on official portals.
- Assessment results are guidance only and are not a professional psychometric diagnosis.
- Course links use broad educational resources and may change over time.
